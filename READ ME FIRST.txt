AFTER UPGRADING: if the page shows an older version than the one you started
(top-left "detailing editor v..."), the browser is showing a page it kept from
the earlier installation. The editor refuses to work with it and tells you to
press Ctrl+F5. Nothing is lost. Your earlier jobs: Open job... -> "Import jobs
from a previous installation..." and type the old folder (for example
C:\mbe8.22) - every saved job found there is added to the job list.

WHICH ZIP: Metal-Building-Editor-<version>.zip is the ready-to-run package -
Start Editor.bat sits at the top of the extracted folder next to the mbdp
folder. building-editor-source-<version>.zip is the plain source tree; its
launcher is in the windows\ sub-folder and (from v0.8.27) also runs from there,
creating the runtime inside windows\ and the job data in data\editor at the
source root.

Extract into a NEW folder and run Start Editor.bat (first start downloads the
private runtime; internet needed once). Keep the folder path short (for
example C:\MBE) - the runtime refuses very long paths. Saving is automatic: the open job is
data\editor\job.json and EVERY job is filed under its job number in
data\editor\jobs\<number>.json. Job > Open job... lists them all; open any
job, the one you leave stays in the list. Duplicate / Delete / Download per
job; Job > Open job file... brings a job in from another computer.
Updating from v0.8.22: extract the new ZIP into a new folder, then Job > Open
job file... and pick the old data\editor\job.json (or copy the old
data\editor folder into the new one before the first start).
Outputs... now offers three print packages: the 22x17 Erection set, the 11x17
Shop set and the Purchasing workbook (the full sheet archive is under
"Archive & references"). Put standard-detail PDFs in data\editor\details\ and
they are appended to the erection set as the D series. The Drawing status
select (REVIEW watermark / FOR CONSTRUCTION) is saved with the job.
See RUN-LOCALLY.md for macOS/Linux and running from source.

New: numbered 5-step sidebar, Outputs dialog by audience, grouped sheet list,
in-app viewer, one dimension grammar. Sheets -> Frame lines: one elevation per
frame line (FL1-..., FL2-...), front/back sidewall framing elevations and the
roof framing plan. Roof datum rule: interior frames BYPASS (roof line = rafter
top + purlin depth); end-wall rafters FLUSH (roof line = top of end rafter =
top of purlin); lean-tos follow the same rule. End default rafter is the
shallowest W whose inside depth takes the purlin + clearance (8in -> W10X12).
